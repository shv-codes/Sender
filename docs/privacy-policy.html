TextCarry

Privacy Policy

Last updated: September 2, 2026

TextCarry is a browser extension that allows users to temporarily transfer selected text between connected browsers and devices.

Information processed

When TextCarry is used, the service temporarily processes:

  • Text that a user explicitly chooses to send.
  • A temporary room/session identifier used to connect browsers.
  • A short-lived six-digit connection code.
  • Temporary connection information required to maintain the real-time connection.
  • IP addresses used temporarily for abuse prevention and rate limiting.

Data storage

TextCarry does not use a database or persistent storage for transferred text.

Messages are held in server memory temporarily while they are being transmitted. Temporary rooms and their associated connection state are removed when the room expires, the connections disconnect, or the server restarts.

TextCarry does not maintain a permanent history of transferred text.

Analytics and tracking

TextCarry does not use analytics, advertising trackers, or telemetry to track how users use the extension.

Third-party hosting

TextCarry's real-time relay service is hosted on Render. The hosting infrastructure may process standard connection and network information, such as IP addresses and timestamps, as part of normal infrastructure operation.

User control

TextCarry only transfers text when the user explicitly uses the extension to send it. The extension does not intentionally collect browsing history, passwords, or unrelated webpage content.

Changes to this policy

This privacy policy may be updated if the functionality or data handling of TextCarry changes.
